# Alphich

Персонализированная новостная аналитика для руководителей крупного бизнеса. Сервис связывает внешнее событие с признаками компании, использует датированную аналитику Альфа-Банка и показывает основания каждого существенного вывода.

Реализованы backend профилей компаний и приёма публикаций, интерфейс просмотра источников, подготовка признаков из CSV, экспертная база PDF, персональный отбор и локальный RAG с E5. Модуль `backend/app/intelligence/` связывает их с извлечением фактов, управляемой сетью `bank_researcher → analyst → verifier`, карточкой, диалогом, аудитом и общим бюджетом. На реальном шлюзе сеть v8 прошла 24 открытых синтетических контроля по инфляции, валюте и зарубежным событиям; отдельно проверены новость о ставке и вопрос по карточке. CLI сохраняет результаты и перепроверяет их без модели. Состав и ограничения проверки описаны в [руководстве оценки](docs/llm-evaluation.md); независимой оценки качества пока нет.

Текущий [отбор](docs/news-selection.md) для каждой новой пары «компания — новость»: **локальная E5 → порог смысловой близости → извлечение фактов и оценка GLM 0–5 → инсайт только при 4–5**. Это относится и к ручному запуску. `NEWS_E5_MIN_SIMILARITY=0.75` — начальный неоткалиброванный cosine-порог, не вероятность; при недоступной E5 платный анализ не запускается. Старые офлайн-метрики ручных правил не являются оценкой качества этой новой схемы.

Инструкции Docker Compose, импорта компаний, демосессий и API находятся в [backend/README.md](backend/README.md).

## Запуск подготовки данных

Нужен Python 3.12 или новее; проверено на 3.13.11. Из корня репозитория:

```sh
PYTHONPATH=backend/src python3 -m alphich.data \
  --input-dir data/synthetic \
  --output-dir data/processed/synthetic-v1
```

В `data/synthetic` находятся полностью вымышленные примеры, включая ошибки и неоднозначности для проверки. Для набора организаторов положите три CSV в `data/raw` и поменяйте входной и выходной каталоги. По умолчанию выбираются `CLIENT` с отчётной выручкой строго выше 15 млрд рублей за 2025 год; охват юрлицо/группа остаётся неизвестным. Отдельную компанию можно выбрать через `--company-id ID`, несколько — повторением флага.

Результат: `companies.jsonl`, `contexts.jsonl`, `quality.json`, `quarantine.jsonl` и `manifest.json`. Исходные данные и результаты игнорируются Git. Для повторного запуска укажите новый выходной каталог: готовые снимки не перезаписываются. Подробности — в [описании модуля](docs/data-pipeline.md).

```sh
PYTHONPATH=backend/src python3 -m unittest discover -s backend/tests -p test_data.py -v
```

Интерфейс подключает ленту, формирование карточки, вопросы, доказательства и журнал через LLM API. [RSS-сборщик](backend/NEWS_INGESTION.md#автоматический-сбор-rss) включён в обычный `docker compose up -d --build`: он круглосуточно читает настроенные источники с интервалом 5 минут, извлекает тексты и отправляет публикации в очередь без LLM-вызовов. Интервал задаётся `RSS_POLL_MINUTES`; сайт показывает heartbeat и расписание. На «Обзоре» и в «Событиях» есть отдельный тестовый «Поиск новостей» с количеством 1–100, случайным отбором из источников, прогрессом и первоисточниками. Ключи, реальные ответы шлюза и журналы расходов сохраняются только в локальных игнорируемых данных.

[Бесплатные проверки AI и поиска](docs/ai-offline.md): общий кэш публичных фактов, окна длинных статей, перепечатки, платёжные признаки, реальные RSS-примеры и аудит сохранённых ответов без новых LLM-вызовов.
