# Alphich

Персонализированная новостная аналитика для руководителей крупного бизнеса. Сервис связывает внешнее событие с признаками компании, использует датированную аналитику Альфа-Банка и показывает основания каждого существенного вывода.

Реализованы подготовка профилей компаний из трех CSV и отдельный инструмент подготовки экспертной базы из PDF. Профили запускаются без сторонних runtime зависимостей; OCR и нарезка находятся в пакете `knowledge/`. API и агент подключают готовые результаты этих инструментов.

## Запуск подготовки данных

Нужен Python 3.12 или новее; проверено на 3.13.11. Из корня репозитория:

```sh
PYTHONPATH=backend/src python3 -m alphich.data \
  --input-dir data/synthetic \
  --output-dir data/processed/synthetic-v1
```

В `data/synthetic` находятся полностью вымышленные примеры, включая ошибки и неоднозначности для проверки. Для набора организаторов положите три CSV в `data/raw` и поменяйте входной и выходной каталоги. По умолчанию выбираются `CLIENT` с исходной выручкой строго выше 15 млрд; это порог по raw значению, без предположения о его единицах. Отдельную компанию можно выбрать через `--company-id ID`, несколько — повторением флага.

Результат: `companies.jsonl`, `contexts.jsonl`, `quality.json`, `quarantine.jsonl` и `manifest.json`. Исходные данные и результаты игнорируются Git. Для повторного запуска укажите новый выходной каталог: готовые снимки не перезаписываются. Подробности — в [описании модуля](docs/data-pipeline.md).

```sh
PYTHONPATH=backend/src python3 -m unittest discover -s backend/tests -v
```
