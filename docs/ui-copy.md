# Тексты интерфейса Alphich

Alphich — новостная аналитика для компании. Сервис отбирает события по данным
компании и роли пользователя, показывает возможное влияние, материалы банка
и основания выводов.

Интерфейс описывает доступные данные и действия. Заголовки называют раздел
или функцию: «Обзор событий», «Подбор новостей», «Данные компании».
Повторяющиеся рекламные слоганы внутри рабочего интерфейса не используются.

## Термины

| Термин | Значение в интерфейсе |
| --- | --- |
| Публикация | Сохранённый текст новости с метаданными и ссылкой на источник |
| Событие | Запись, доступная после обработки публикации |
| Анализ | Результат оценки возможного влияния события на компанию |
| Позиция банка | Вывод из найденных материалов банка с указанием источника и даты |
| Выводы модели | Автоматически сформированные выводы, отделённые от фактов и позиции банка |
| Значимость | Оценка применимости события к компании; не размер финансового риска |
| Профиль компании | Исходные данные, используемые для отбора событий и анализа |

«Инсайт» и «разбор» не используются как дополнительные названия анализа.
Имена компонентов и поля API от этого правила не зависят.

## Правила

- Кнопка называет действие: «Подобрать новости», «Подготовить анализ»,
  «Открыть анализ», «Сохранить оценку». Открытие готового результата и запуск
  нового анализа описываются разными словами.
- Подсказка объясняет область действия или следующий шаг. Она не повторяет
  заголовок другими словами.
- Не обещаем найти позицию банка или подтвердить влияние, если это зависит
  от доступных материалов. Используем «возможное влияние» и явно показываем
  отсутствие подтверждений.
- Автоматические ответы обозначаются как автоматические. Название раздела
  «Вопросы по событию» не подразумевает участие сотрудника банка.
- Загрузка, ошибка и пустая лента описываются отдельно. При ошибке загрузки
  не предлагаем запускать подбор так, будто в ленте заведомо нет событий.
- Ограничения данных и сведения о расходах сохраняются там, где помогают
  оценить вывод или принять решение о запуске анализа.
- Заголовки пишутся без декоративной точки. Термины «контекст», «фокус» и
  «повестка» не заменяют конкретное название данных или функции.

## Примеры замены

| Было | Стало |
| --- | --- |
| Меньше шума. Больше ясности. | Обзор событий |
| Ваш следующий важный инсайт | Подбор новостей |
| Найти важное | Подобрать новости |
| Ваша оптика | Приоритеты анализа |
| Пульс повестки | Значимость событий |
| Ваш бизнес в контексте | Данные компании |
| Спросить аналитика | Вопросы по событию |
| Разобрать — для уже готового результата | Открыть анализ |

Эти правила относятся к текстам интерфейса. Содержимое публикаций и ответы
аналитического API отображаются как получены; фронтенд не переписывает факты
или сгенерированные выводы ради соответствия стилю.
