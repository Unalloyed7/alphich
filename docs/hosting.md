# Размещение Alphich на неделю без собственных расходов

Выбор на 20 октября 2026 года: Cloud.ru Evolution, обычная CPU виртуальная машина за счет стартового гранта 4000 бонусов. Пользователь подтвердил наличие российского номера и российской карты. Получение гранта нужно проверить до создания платных ресурсов: предложение рассчитано на подходящих новых пользователей, а не на любой существующий аккаунт.

## Основная конфигурация

| Параметр | Выбор |
| --- | --- |
| Вычисления | 4 vCPU с гарантированной долей 100%, 16 GB RAM |
| Диск | Один SSD NVMe 40 GB |
| ОС | Публичный Linux образ Ubuntu 24.04 |
| Сеть | Один публичный IPv4 |
| Приложение | Один Docker Compose: reverse proxy/frontend, API, worker, PostgreSQL с pgvector |
| Эмбеддинги | Один локальный E5-base в worker, без GPU |
| Генеративные модели | Предоставленный организаторами API и его отдельный бюджет |
| Срок | 7 дней, после выгрузки данных завершить размещение |

16 GB — выбранный запас под E5/PyTorch, PostgreSQL, приложение и файловый кэш. Это инженерная оценка для небольшой аудитории хакатона; фактические RAM и задержки проверяются первым нагрузочным прогоном. Пакетный OCR, исходный ETL и основные embeddings готовим локально. На сервере обрабатываются запросы, новые публикации и обновления.

Модель загружается только в одном процессе worker. API не создает свою копию E5; embedding операции выполняются последовательно или ограниченными batch. Число параллельных генеративных задач ограничено независимо. Собранный фронтенд отдает reverse proxy с того же домена.

## Стоимость и покрытие грантом

Расчет по тарифу Evolution Compute версии 261014, действующему с 14.10.2026. Цены ниже с НДС, период — 168 часов. Это расчет выбранных позиций, а не подтвержденный счет конкретного аккаунта. [Актуальная таблица](https://cloud.ru/documents/tariffs/evolution/evolution-compute), [PDF тарифа](https://cdn.cloud.ru/docs/legal/tariffs/evolution/current-version/evolution-compute.pdf).

| Ресурс | Ставка | За 7 дней |
| --- | ---: | ---: |
| ВМ 4 vCPU / 16 GB | 7,9788 ₽/час | 1340,44 ₽ |
| SSD NVMe 40 GB | 0,01586 ₽/GB/час | 106,58 ₽ |
| Один публичный IP | 0,2074 ₽/час | 34,84 ₽ |
| Базовая сумма | 8,8206 ₽/час | 1481,86 ₽ |

Отдельная привязка IP, исходящий трафик, дополнительные ресурсы и резервные копии не включены. В консоли нужно проверить выбранный тип IP и полный estimate. Цель для недели — уложиться в 2000 бонусов со всеми фактически включенными услугами, оставив остальные 2000 запасом. При той же базе десять дней стоят примерно 2117 ₽ до дополнительных услуг; срок нельзя продлевать автоматически.

Грант эквивалентен 4000 ₽ и действует 60 дней. В правилах предусмотрены регистрация нового физического лица, постоянно проживающего в РФ, и привязка карты; возможен отказ в выдаче. Бонусы расходуются приоритетно. После исчерпания гранта правила допускают списание денег с привязанной карты. Поэтому нулевые собственные расходы зависят от фактического получения гранта и завершения ресурсов до его исчерпания. [Полные условия](https://cloud.ru/documents/promotions/active/4000-rubles-testing), [получение бонусов](https://cloud.ru/docs/billing/ug/topics/guides__billing_bonus).

Опция «Порог баланса» предусматривает автопополнение. Ее отключение само по себе не доказывает жесткий нулевой лимит платежей по договору. Используем контроль расхода и своевременное завершение ресурсов; уведомление о бюджете не считаем гарантированным ограничителем начислений. [Описание опции](https://cloud.ru/docs/billing/ug/topics/concepts__limit_payment).

## Порядок запуска

1. Зарегистрировать подходящий аккаунт, привязать карту и убедиться, что 4000 бонусов действительно зачислены. По документации зачисление может занять сутки.
2. До создания ВМ проверить в консоли весь расчет: 4/16 со 100% CPU, диск, IP и покрытие выбранных услуг грантом. Если требуется собственный платеж, остановить этот вариант и использовать резерв.
3. Создать одну ВМ, загрузить подготовленный код/образы, исходные материалы и обработанные данные в закрытые каталоги. Не включать GPU, платные Marketplace образы или managed сервисы.
4. Запустить Compose, миграции и импорт. Сохранить данные PostgreSQL и модели в постоянных volumes; ограничить размер журналов.
5. Подключить бесплатное DNS имя и HTTPS. Проверить приложение из внешней сети и доступность API организаторов, RSS и весов модели.
6. Прогнать одновременно 3–5 демопользователей: память, очередь, новую публикацию, холодный старт и попадание в кэш. Если RAM/задержка выше ожиданий, сначала ограничить параллелизм; не увеличивать тариф автоматически.
7. Проверять фактический расход ежедневно и после изменения конфигурации. На шестой день подготовить выгрузку и решение о завершении на седьмой.

Остановка ВМ прекращает вычислительные начисления, но диск и IP продолжают тарифицироваться. После резервного копирования удалить все ненужные тарифицируемые ресурсы и проверить остаток в контроле затрат. Эти действия выполняются владельцем стенда по завершении недели. [Правила тарификации](https://cloud.ru/docs/virtual-machines/ug/topics/pricing).

## Адрес сайта

Для бюджета 0 подойдет свободный поддомен бесплатного [DuckDNS](https://www.duckdns.org/), направленный на IP сервера. Доступность конкретного имени проверяется при регистрации. [Caddy](https://caddyserver.com/docs/automatic-https) получает HTTPS сертификат для публичного DNS имени при корректных DNS и доступных 80/443; его каталог сертификатов сохраняется в volume. Покупать домен для недельного демо не требуется.

Для резервного локального демо есть [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/): он дает временный публичный URL, но требует включенного компьютера и не имеет гарантии доступности. Используем polling задач: Quick Tunnel не поддерживает SSE. Никакой tunnel, DNS или аккаунт еще не созданы.

## Почему другие бесплатные варианты не основные

| Вариант | Что изменяет выбор |
| --- | --- |
| [Hugging Face Docker Spaces](https://huggingface.co/docs/hub/spaces-overview) | CPU Basic не тарифицируется почасово, но создание нового Docker/Gradio compute Space требует платного плана. Также исходящие порты ограничены 80/443/8080 |
| [Cloud.ru Free Tier VM](https://cloud.ru/docs/virtual-machines/ug/topics/overview__free-tier) | Новая бесплатная ВМ недоступна зарегистрировавшимся после 30.06.2026. Выбранный вариант использует грант для обычной ВМ |
| [Yandex Cloud](https://yandex.cloud/ru/docs/billing/quickstart/) | Текущая инструкция говорит о платном старте новых клиентов; старые предложения про автоматический стартовый грант не берем за основу |
| [Render Free](https://render.com/docs/free) | 512 MB web service и сон; E5-base/PyTorch в этот план не закладываем. Возможный ONNX INT8 small требует отдельной проверки памяти и изменения развертывания |
| [Neon Free](https://neon.com/pricing) | Подходит как отдельная небольшая PostgreSQL/pgvector, но не заменяет CPU хост для Python/E5. На выбранной ВМ отдельный провайдер БД не нужен |
| [Oracle Free Tier](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) | Ресурсы привлекательны, но доступность регистрации, емкость региона и idle reclaim создают неопределенность; есть отдельные ограничения услуг для РФ |

Если Cloud.ru не выдаст грант, резерв — имеющийся компьютер команды с тем же Compose и временным публичным tunnel. Его ресурсы и сеть нужно проверить; постоянно включенный компьютер и стабильное соединение становятся обязательными. Малый бесплатный Render рассматриваем только после измерения ONNX small под лимитом памяти; размещаемость пока не проверена.

## Граница готовности

Хост выбран, расчет и условия проверены по публичным источникам. Регистрация, выдача гранта, реальная конфигурация ВМ, сетевой доступ и нагрузочный тест еще не выполнены. Они входят в первые часы backend направления, чтобы проблемы регистрации не обнаружились перед защитой.
