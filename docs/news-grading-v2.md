Данные содержат регион регистрации, а не доказанный портфель объектов/маршрутов. Единицы выручки не установлены; размеры компаний считаются крупными по условию задачи без выдуманного пересчёта денег.

4–5 требуют одновременно отраслевой применимости, подходящей географии и существенного масштаба. Чужой локальный кейс ограничен 1, единичный небольшой продукт/пилот — 2, неизвестный масштаб/география или законопроект — 3. Регион регистрации не даёт доказательства участия в конкретном проекте. Для 5 нужны подтверждённая прямая обязанность/критическое событие и конкретное действие.

Стандарт подключён к API feed: `relevance_grade` 0–5, `relevance_selected`, `relevance_assessment` и `grading_version` вычисляются для новых событий, без чтения заранее записанных 150 оценок. В ленту проходят только 4–5. Старый `priority` 0–100 остаётся внутренним порядком и не переводится арифметически в новую шкалу.

Extractor v14 извлекает `geographic_scope`, `market_scope`, `impact_scale`, `event_status`, `business_effect`, `applicability`, `effective_from`. Существующий независимый проход проверки атрибутов проверяет и эти поля; дополнительных генеративных вызовов не добавлено. Широкий охват сам по себе не доказывает существенность: для 4 нужны `sector_wide` и `impact_scale=material`, прямая деятельность/подтверждённый финансовый продукт и применимый рынок. Для 5 дополнительно нужно уже действующее обязательное требование ко всей подтверждённой деятельности. Неподтверждённые условия применимости ограничивают оценку 3.

Оценка строится по одному согласованному факту/каналу с точными source spans и ID признаков компании. Масштаб одного факта не объединяется с географией другого. Регистрация не заменяет места операций. Единицы выручки неизвестны: доля эффекта в обороте не вычисляется. Нет доказательств точного продукта, контрагента или груза — нет соответствующего прямого канала.

Без проверенного масштаба/географии старые извлечения и сырые новости не проходят порог: они остаются в событиях и очереди извлечения. На HTTP GET генеративная модель не вызывается. Для новых полей нужна новая явно запущенная задача анализа; существующие карточки не пересчитываются платно в фоне. Ручной разбор доступен и ниже порога, но содержит оценку и не повышает её. На новых настоящих ответах шлюза v14 пока не проверялся; контрольные проверки используют заглушку модели, поэтому качество семантического присвоения атрибутов ещё предстоит измерить.
