## Проверенные поля публикации

Проверена по одной реальной статье каждого перечисленного ниже издателя.
Это подтверждение формата примера, а не гарантия неизменности всех шаблонов.

| Источник | Поле / ограничение |
| --- | --- |
| Интерфакс | `meta[property="article:published_time"]`, `meta[itemprop="datePublished"]`, JSON-LD `datePublished` |
| Retail.ru | JSON-LD `datePublished`, ISO 8601 |
| РУССОФТ | JSON-LD `datePublished`, ISO 8601 |
| Elec.ru | `time[itemprop="datePublished"][datetime]`; отдельный `dateModified` не подходит |
| АТОР | `article:published_time` / JSON-LD; другие `time` на странице могут быть будущими вебинарами |
| Стройгазета | JSON-LD `datePublished` и `time.news-date-time`, русское название месяца; другие `article_date` относятся к рекомендуемым статьям |
| Агроинвестор | `time[itemprop="datePublished"]`, атрибут **`datatime` с опечаткой** и текст; русский месяц |
| Минтранс | `p.article-inf-date`, текст `Опубликовано 21 Октября 2026`; месяц регистронезависимый |
| Минздрав | `p.timestamps > time`, текст начинается `Материал опубликован`; второе `time` — обновление |
| ФНС | `div.news__time.single-news__time`, явное `Дата публикации: 21.10.2026 15:15` |
| АВТОСТАТ | `span[itemprop="datePublished"][content]`; видимое «вчера» не используется |

Предпочтительный начальный интервал истории — **2025-01-01 … 2026-10-22**.
Настройка в manifest рекомендательная: фактический сборщик обязан явно
применять выбранное окно и фиксировать его в отчёте. Нумерация карт не
универсальна: у РУССОФТ карта 16 новее карты 1, у АВТОСТАТ карта 7 содержит
2008 год. `lastmod` и порядок ссылок не используются как замена даты статьи.

## Ограничения сбора

1. `robots.txt` Стройгазеты и Агроинвестора запрещает `PAGEN`: используем
   объявленные карты, а не запрещённую постраничную навигацию. Интерфакс
   запрещает `/Infinite` и `/search`, поэтому они не используются.
2. Sitemap `lastmod` не подтверждает публикацию. У Агроинвестора у старых
   материалов наблюдался свежий одинаковый `lastmod`; дату берём из статьи.
   Дата в URL также не заменяет явное подтверждение публикации.
3. Проверка даты относительно `as_of` и будущих событий обязательна. Обучение
   на истории допустимо при корректном историческом контексте; старая статья
   не выдаётся за новую новость в текущей ленте.
4. RUSSOFT и АТОР содержат заявления участников, Elec.ru — новости поставщиков.
   Помечаем происхождение и жанр. Реклама, поздравления, подборки отпусков,
   потребительские советы и приглашения на мероприятия не включаются ради
   достижения счётчика 10 000. В manifest есть точные
   `excluded_title_patterns` и `excluded_article_path_prefixes`; они должны
   применяться кодом сборщика с записью причины карантина. Нечёткий жанр
   остаётся `genre_unknown` для проверки, а не считается доказанной рекламой
   или отрицательной меткой релевантности.
5. Небольшие локальные **деловые** события полезны как трудные отрицательные
   примеры; отсутствие жёлтых материалов не означает, что все новости должны
   получить положительную оценку.
6. Открытый доступ не равен лицензии на публичное распространение полного
   текста. Сырые тексты и профили по умолчанию остаются в приватном корпусе;
   в Git сохраняются код, конфигурация и агрегаты.
7. АВТОСТАТ/АТОР через поисковый прокси отвечали 403, а обычный HTTPS GET — 200.
   Если рабочий сборщик получает 403, он останавливается для этого источника,
   не меняет личности и не обходит ограничение.
8. ЕЭК не добавлена в исторический конфиг: в текущем окружении ошибка цепочки
   TLS. Минстрой и ФАС не добавлены из-за таймаутов TLS. Проверка сертификатов
   не отключалась. Альтернативный sitemap Минздрава на `rosminzdrav.ru` также
   имеет проблему TLS; используется доступный архив `minzdrav.gov.ru`.

## Использование корпуса

Темы источника обозначают кандидатов для распределения, а не целевую метку.
Пары строятся с реальными снимками компаний и отбором по темам, дополненным
межотраслевыми и географическими отрицательными примерами. Вход модели не
содержит оценки/обоснования LLM-учителя. Одна статья, её редакции и перепечатки
не разделяются между train и test. Будущий holdout проверяется людьми вслепую;
его нельзя использовать для подбора порога или промпта.

Отдельно фиксируется задача: значимость **в момент публикации** и пригодность
для **сегодняшней** ленты различаются. Иначе все старые статьи автоматически
станут отрицательными только из-за лимита свежести. Историческая разметка с
современным профилем требует явной пометки предположения о неизменности
профиля; неизвестная дата снимка не превращается в подтверждённый профиль
компании на 2025 год. Итоговый независимый holdout должен соответствовать
реальному времени и бизнес-контексту использования.
