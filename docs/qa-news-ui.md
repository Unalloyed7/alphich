# Ручная проверка новостного интерфейса (без AI)

## Что добавлено

- `GET /api/v1/jobs?limit=20`: последние задачи текущей **демосессии**, вместе с заголовком публикации и временем постановки. Не даёт читать чужие задачи, включая другую сессию той же компании.
- `GET /api/v1/companies/{company_id}/events?limit=20&offset=20`: постраничное чтение событий конкретной доступной компании (0 ≤ offset ≤ 100000, 1 ≤ limit ≤ 50). Старый ответ `{ "items": [...] }` сохранён.
- В разделе «События» есть клиентский поиск только **по загруженным** заголовкам, «Показать ещё», счётчик видимых записей.
- Панель последних задач восстанавливает историю по серверному токену после обновления страницы; при новом входе выдаётся новый токен, поэтому история задач предыдущей демосессии недоступна. Сами события доступны новой разрешённой сессии той же компании.

## Обновить локальный стенд без сброса БД

```sh
git switch -c feat/news-ui-operability # после git switch main и git pull
git apply --check ~/Downloads/alphich_news_ui_operability.patch
git apply ~/Downloads/alphich_news_ui_operability.patch
docker compose up -d --build api frontend
```

Нет изменений схемы БД, миграция не нужна. Не выполняйте `docker compose down -v`.

## Сценарий проверки

1. Войти на `http://127.0.0.1:5173` в импортированную демокомпанию (например `DEMO_A`) под CFO.
2. Добавить две **разные** публикации с заголовком (не менее 6 символов) и текстом (не менее 30 символов).
3. Убедиться, что worker обработал публикации; открыть подробности событий и первоисточники.
4. Обновить страницу `Cmd + R`: недавние задачи должны вернуться из PostgreSQL. Список задач сохраняется только в рамках текущей демосессии и доступен до окончания её срока.
5. В «Событиях» набрать часть заголовка: отображаются только подходящие среди загруженных событий. Очистить поиск.
6. Чтобы проверить кнопку «Показать ещё», отправить более 20 разных публикаций. Первые 20 доступны сразу; остальные загружаются партиями по 20. Новые публикации могут изменить смещения: при этом нажать «Обновить».
7. Зайти под другой компанией и убедиться, что чужие события и задачи не появляются.

Проверки Python:

```sh
cd backend
python -m pytest -q
```

Ограничения: отсутствуют AI-извлечение и аналитические карточки; полнотекстовый серверный поиск не реализован; источники, вставленные пользователем, не верифицируются; браузерные end-to-end тесты пока не автоматизированы.
