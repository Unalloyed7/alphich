# Результаты разметки: снимок 24 октября 2026

Разметка продолжает работать на VPS. Это текущий снимок, а не итог всей очереди. Точные счётчики, время и SHA-256 файлов — в `summary.json`.

`teacher-decisions.jsonl` содержит принятые предложения моделей и происхождение каждой оценки: `pair_id`, `article_id`, роль, модель, batch/run, версии и хеши входа и промпта. `machine-consensus-decisions.jsonl` содержит бинарное согласие двух разных моделей по `grade>=4`. Точная оценка внутри отрицательного класса остаётся предложением основного учителя; диапазон оценок сохранён.

Это экспорт решений без полных текстов новостей, профилей компаний, объяснений с финансовыми данными и ключей. Для обучения решения присоединяются к соответствующим приватным входам по `pair_id`; нужно сверять `input_hash`, `prompt_hash` и версию критериев. Сам экспорт не является полноценной входной выборкой `read_dataset`.

`legacy-pre-case-calibration` сохраняет исторические диагностические метки. `case-business-significance-v1` — уточнённые критерии v9. Эти группы не объединяются незаметно при обучении. Текущий v9 consensus частичный: отсутствие второй модели в снимке означает незавершённую проверку, а не отрицательный класс.

Согласие моделей — машинный silver. Независимая accuracy не измерена; human gold и завершённая обученная CPU-модель не заявляются. Документы: [фактическое выполнение](../../../docs/automatic-labeling-results-2026-10-24.md), [runbook](../../../docs/automatic-labeling-runbook.md).

`business-target-consensus-decisions.jsonl` — отдельная производная тех же ответов с политикой `business-binary`: 95 согласованных пар, включая три положительные пары по двум новостям. Обе модели должны подтвердить `grade>=4`, область применимости и общие факты компании. Для четвёрки допускаются различия в стадии события и сочетание смешанного влияния с конкретным механизмом; расхождения сохранены в метаданных. Это цель бизнес-значимости для обучения; `publishing_permission=false` не разрешает автоматически публиковать новость сегодня. Исходный строгий consensus сохранён отдельно.
